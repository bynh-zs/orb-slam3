# STEP3 · IMU 预积分 ΔR / Δv / Δp

## 这一步解决什么问题

IMU 是 200Hz，图像是 20Hz。没法把 10 个 IMU 采样直接塞进优化，也不能每次优化迭代都把 10 个采样重新积分一遍（滑窗十几帧、每帧十来次迭代，重算是灾难）。

所以要做的是：**把两个图像帧之间的所有 IMU 采样，压成一个相对运动量**，即旋转增量 ΔR、速度增量 Δv、位置增量 Δp。压完之后，优化时只用一个「预积分因子」就能约束两帧之间的运动。

## 积分公式（中值积分）

对两个采样之间的时间间隔 dt：

```
ΔR  ← ΔR · Exp( (w_k + w_{k+1})/2 · dt )
Δv  ← Δv + ΔR · (a_k + a_{k+1})/2 · dt
Δp  ← Δp + Δv · dt + 0.5 · ΔR · (a_k + a_{k+1})/2 · dt²
```

三个要点：

- 用**中值**（相邻两个采样的均值）而不是左端点，精度从 O(dt) 提到 O(dt²)。
- 旋转用指数映射 `Exp(ω dt)` 增量式左乘，不能用欧拉角的线性相加。
- Δv / Δp 的更新顺序是先更新 Δv 再用新的 Δv 更新 Δp（顺序反了会引入一阶误差）。

## 为什么要「预」积分

预积分的「预」不是「提前算」，而是**相对某个参考帧预先把量算好，让它与初值、与零偏解耦**。

直白说：优化过程中位姿、速度、零偏都在变。如果每次迭代都从第一个采样重新积分，计算量随迭代次数线性增长。预积分把「两个采样之间的相对量」提前算出来存好，迭代时只需做一阶修正（`ΔR(bg)` 的雅可比修正），量级小、可复用。

本仓库当前实现的是基础版：固定零偏、中值积分、不含零偏雅可比修正。零偏修正留在 STEP5 之后引入，因为那个修正项只有在 bg 真的被估出来之后才有意义。

## 图怎么读

两张图：Δp 模长随时间、Δv 模长随时间。

- **静止段**：曲线应当贴着一个小常数不动。本次实测每条帧对的 Δp 恒为 `(0.011, 0, -0.010)` m，也就是约 1.5cm 的微小位移。这个「恒定」本身就是最有力的验收证据 —— 说明积分没有累积漂移，也没有把时间戳算错。
- **运动段**：曲线开始上升，形状应与真实运动趋势一致。
- 如果曲线抖成噪声，通常是 dt 用错（比如把纳秒当秒）或单位错（角速度用成 deg/s）。

## 验收标准与实测值

| 指标 | 要求 | 实测 |
|---|---|---|
| 每帧对 ΔR | 单位阵附近（静止） | 接近单位阵 |
| 每帧对 Δv | 小量 | 小量 |
| 每帧对 Δp | 恒定常数 | (0.011, 0, -0.010) m，全程不变 |
| 数值稳定性 | 不发散 | 稳定 |

「每帧对的 Δp 完全相同」这个现象值得注意：说明这段数据里靠前的部分是静止或匀速的，且帧间隔严格相等（200,202,204…每帧间隔 0.1s）。STEP4 的视差选帧、STEP5 的线性对齐都依赖这个前提。

## 与 STEP5 的衔接

STEP5 的线性对齐要解这个方程（概念形式）：

```
视觉测得的 ΔR_ij  ≈  ΔR_imu(bg) · R_ic 的组合
视觉测得的 Δp_ij·s  ≈  ∫∫ (ΔR_imu · a)  ─  0.5 · g · t²
```

左边那个 `s` 就是单目的尺度自由度。右边含重力项。因为 STEP3 已经把 `ΔR_imu`、`Δv`、`Δp` 算成了可查表的值，STEP5 只需组装一个线性方程组，不用重新积分。

## 常见错误

- 用欧拉积分代替中值积分，静止段的 Δp 会出现几百米的假位移。
- 时间戳 ns 不转 s，dt = 5e9 秒。
- 角速度单位混淆（EuRoC 是 rad/s）。
- 首帧没有上一个采样就硬积分，导致第一段预积分量是垃圾。
- 把预积分量当成「绝对位姿」用。它是**相对量**，且只在两帧之间有效，跨三帧不能直接相乘复用（要逐段递推）。
