# STEP4 · 滑窗 SfM 初始化（无尺度）

## 这一步解决什么问题

到此为止只有「图像的像素」和「IMU 的相对运动量」。STEP4 要产出第一份 3D 结构：**每帧相机位姿 + 一批 3D 点坐标**。

这里有个必须一开始就想清楚的限制：单目恢复出来的空间结构**没有绝对尺度**。同一个场景放大 10 倍、相机位移也放大 10 倍，投影到图像上完全一样。所以 STEP4 输出的 t 只是方向正确、长度任意。这不是缺陷，是单目的自由度，STEP5 才用 IMU 把它定死。

## 真实 VINS 的初始化长什么样

对应官方 `initial/initial_sfm.cpp::GlobalSFM::construct()`，骨架是：

1. 在滑窗里挑一对**视差足够大**的帧作参考（基线太小，三角化精度会炸）。
2. 这对帧用**五点法**求本质矩阵，再 `recoverPose` 得到相对 R、t。
3. 三角化这批点，得到初始 3D 地图。
4. 其余帧用**已知 3D 点 + 2D 观测**做 PnP，求各自位姿。
5. 用所有帧对所有点的观测做一次**全局 BA**，把误差摊平。
6. 若还有帧对没参与，补充三角化以加密地图。

本仓库按这个骨架实现，参数按 EuRoC 真实量级设定。

## 两个坐标空间（这一步的核心设计）

v3 版本把每个观测存两份坐标：

```
Obs {
    Point2f px;   // 原始像素坐标，只用于可视化和最终误差换算
    Point2f nv;   // undistortPoints 后的归一化坐标，所有几何计算用它
}
```

- 三角化、重投影残差、BA 残差，**全部在归一化坐标空间**做，阈值 `NORM_THR`。
- 像素坐标只用来画图、以及把归一化误差换算成「约等于多少 px」便于人看。

为什么要这么设计，见 [pitfalls.md](pitfalls.md) 第 2 条：EuRoC 的 k1 = -0.283 是强畸变，边缘像素的畸变位移能到 10~20px。在像素空间直接把「无畸变模型投影出来的点」和「带畸变的真实观测」相比，等于系统性惩罚图像边缘，会把大量正确点判成错误。

## 手写 BA 的残差与更新

对每个观测：

```
r = projectN(R_i, t_i, X_j) − nv_ij
J_pose = ∂r/∂(R_i, t_i)，J_point = ∂r/∂X_j
```

法方程 `(JᵀJ + λI) Δ = −Jᵀr`，解出增量后更新位姿与点。λ 的作用是把奇异方向压住 —— 单目无尺度，法方程天然有一个零空间方向（整体缩放），不压住会直接发散。

## 验收标准

| 指标 | 要求 | 含义 |
|---|---|---|
| 初始三角化点数 | 300+ | 少于这个量后续 PnP 与 BA 都不稳 |
| 4 个 PnP 帧内点 | 每帧几十~上百 | 3D-2D 对应充分 |
| BA 前平均重投影 | < 0.1（归一化） | 初值本身就得靠得住 |
| BA 后平均重投影 | < 0.0022（≈1px） | 收敛 |
| 可视化 | 点云变密、6 个相机中心连成一条线 | 结构与运动一致 |

「6 个相机中心连成一条线」这一条很关键：MH_01 起飞段是近似直线的平移，如果画出来的相机位置散成一团，说明 t 的估计就是错的，跟 BA 收敛与否无关。

## 当前状态：未通过

实测（v3 归一化空间版，像素空间求 F + `E = KᵀFK`）：

```
6 帧全链跟踪特征 526
视差选帧 (0,5) = (帧200, 帧210)，平均视差 244.9 px
5 点法内点 419 / 526
诊断: F 内点=419，过深度检查=416，过重投影保留=10
PnP 帧202 内点 7，帧204 内点 0，帧206 内点 0，帧208 内点 8
补充三角化后总点 518
BA: 3108 残差观测，1584 优化参数
BA 前平均重投影误差: 586.33（归一化，≈268922 px）
```

现象很清楚：416 个点通过了深度检查（说明它们在两相机前方），但重投影误差巨大，只有个位数通过 0.01 的归一化阈值。

理论上这里应当自洽：参考帧位姿是 `[I|0]`，三角化输入是 `obs[l].nv`，那么重投影 `(X.x/X.z, X.y/X.z)` 应当**恒等于** `obs[l].nv`。实际不等，说明问题不在阈值松紧，而在三角化输入/齐次符号或位姿矩阵本身。排查路径与已排除项见 [pitfalls.md](pitfalls.md) 第 3、6、7 条。

这一步没通过之前不进入 STEP5 —— 因为 STEP5 的线性对齐要拿 STEP4 的位姿当输入，输入是错的，STEP5 只会把错误放大成「尺度乱跳」。

## 常见错误（本步专属）

- 三角化不做 RANSAC 内点过滤：外点三角化出来的深度会落在相机后方或几公里外。
- 深度检查用 `X.z > 0` 但忘了归一化，齐次坐标 `w` 为负时符号会整体翻转。
- PnP 用的 3D 点是「无尺度」的，却按米制设了 `reprojectionError` 阈值 —— 无尺度意味着这个阈值没有物理意义，只能用它做内点筛选，不能用它判断精度。
- BA 优化时同时放开尺度和位姿，没有先验约束 → 漂到无穷。
