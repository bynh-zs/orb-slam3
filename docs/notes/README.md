## 写笔记的约定

- 每篇回答三个问题：**这一步解决什么问题、具体怎么做、图/数字怎么读**。不写「本步骤非常重要」这类没有信息量的过渡句。
- 参数只写**实际用的值**，不写「一般取 0.01~0.1」。
- 踩过的坑单独成篇，附当时的输出，便于将来对照。
- 不追求覆盖全部理论，只覆盖这条流水线上真的会用到、且真的会错的部分。

## 与 Word 讲义的关系

课程提交用的 Word 讲义另存，各有各的用途。这里只放能 diff、能搜、能在网页上直接读的 markdown。
