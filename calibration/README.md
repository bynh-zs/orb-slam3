# 标定

标定是 SLAM 的前置条件：内参错一点，三角化的深度就系统性偏；相机-IMU 外参错一点，VINS 的对齐就会把误差当成「尺度」。

本目录放**流程、参数与脚本**。原始棋盘格图片（每组十几张、单张几 MB）不入库 —— 它们是可重新采集的过程数据，进 Git 只会让仓库膨胀。

## 四类标定及其顺序

| 顺序 | 标定什么 | 用什么 | 产出 |
|---|---|---|---|
| 1 | 相机内参 + 畸变 | 棋盘格多姿态图像 + 张正友标定 | `fx fy cx cy k1 k2 p1 p2` |
| 2 | 双目外参（R、t） | 同一棋盘格被两个相机同时看到 | 基线、相对旋转 |
| 3 | IMU 内参（噪声、随机游走） | 静止段长时间采集 + `imu_utils` | `gyr_n gyr_w acc_n acc_w` |
| 4 | 相机-IMU 外参（R_ic、t_ic） | 手持相机做充分激励 + `kalibr` | `R_ic`、`t_ic` |

顺序不能乱：内参不准，外参标出来也是错的；IMU 内参不准，`kalibr` 的联合优化会不收敛。

## 采集要点

- 棋盘格要覆盖图像**四角**，不能只在中间晃。边缘的畸变系数只有在边缘有观测时才可辨识 —— EuRoC 的 `k1 = -0.283` 就是强畸变，中心区域完全看不出这个量级。
- 双目外参：棋盘格必须**同时完整出现在两个视野**里，且姿态要多（倾斜、远近都来几组）。
- IMU 内参：设备静止放置两小时以上。`imu_utils` 靠 Allan 方差分离噪声密度与随机游走，采集时间短会把两者混在一起。
- 相机-IMU 外参：三个轴都要有充分转动（不是平移），否则某个轴的旋转不可观。

## 已用到的工具

`imu_utils`（IMU 内参）、`kalibr`（相机-IMU 联合标定）、MATLAB Camera Calibrator（相机内参与双目外参）。

安装与配置的坑记在本地笔记里，未入此仓库。

## EuRoC 的现成参数

用公开数据集时不必自己标，直接取 `mav0/cam0/sensor.yaml`：

```
fx 458.654  fy 457.296  cx 367.215  cy 248.375
k1 -0.28340811  k2 0.07395907  p1 0.00019359  p2 1.76187114e-05
```

自采数据才需要走上面四步。注意 EuRoC 的 `R_ic` 与 `t_ic` 也在 `sensor.yaml` 里 —— VINS 的 STEP5 直接读它，不自己做在线标定。
