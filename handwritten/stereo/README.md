# 双目前端 · 12 步手写实现

在单目的基础上加了第二只眼睛（cam0 + cam1），因此多出两件事：**极线约束（特征只需沿极线搜索）**和**带真实尺度的三角化**。

## 双目与单目的关键差别

单目三角化出来的点只有方向，长度任意；双目因为两相机之间的基线是已知常数，同一个点在两幅图上的视差 `d = u_l - u_r` 直接决定深度：

```
Z = f · B / d        f 焦距，B 基线，d 视差
```

所以双目第一步就拿回了尺度。这是双目相对单目最大的优势，也是它不需要「视觉惯性对齐」这一步的原因 —— VINS 里那个解尺度的线性对齐，在双目里由基线直接给定了。

另一个差别是三角化与 PnP 的关系：双目里两件事并非串行「先三角化再 PnP」，而是在同一帧上互为因果 —— 用已三角化的点做 PnP 求位姿，再用位姿去三角化新点，逐步迭代。这和单目的滑窗初始化是同一种结构，只是双目每帧都有基线，不必等攒够视差。
