# 单目前端 · 12 步手写实现

把 ORB-SLAM3 的单目前端拆成 12 步，用 OpenCV 一手写出来，每步独立运行、独立出图。

覆盖的环节：角点提取 → 描述子构建 → 跨视图特征匹配 → 多视图三角化 → PnP 求 R/t → 位姿累积。整体路线与 ORB-SLAM3 的单目初始化一致，但不含回环、地图管理与后端优化 —— 那些属于框架层，不在「前端」范围内。

## 状态

流程已跑通并逐图验收过，源码待从工作机同步（`bash scripts/collect.sh`）。

同步后的结构：

```
handwritten/mono/
├── step1/ … step12/      源码 + CMakeLists.txt
└── results/step1/ …       每步输出图
```

## 与双目、VINS 的关系

单目这条线的作用有两个：

一是提供**最干净的几何基线** —— 单目没有尺度、没有第二个相机约束，所有几何问题（对极几何、三角化退化、PnP 尺度模糊）都暴露得最彻底。双目和 VINS 都是在它之上加约束。

二是作为 VINS 的前置：VINS 的 STEP4（SfM 初始化）本质上就是单目这条线的滑窗版。单目里踩过的三角化与 PnP 的坑，在 VINS 里会以更隐蔽的形式重新出现。
